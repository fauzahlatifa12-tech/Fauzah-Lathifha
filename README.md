#Draela

##Deksripsi

Draela adalah website yang menyediakan informasi mengenai drama korea (k-drama). Website ini dibuat untuk membantu pengguna melihat informasi drama, detail pemain, rating, tahun rilis, jumlah episode, serta trailer drama.

##Fitur
-Menampilkan daftar drama korea 
-Pencarian drama
-Filter berdasarkan tahun rilis
-Menampilkan datail drama
-Menampilkan informasi pemain dan karakter
-Menampilkan rating dan jumlah episode 
-Menampilkan trailer drama
-Fitur favorite
-Registrasi dan login
-Profile pengguna
-Tampilan responsive untuk berbagai ukuran layar

##Menggunakan

-HTML
-CSS
-JavaScript
-API
