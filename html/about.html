TENTANG WEBSITE

Draela adalah website project sederhana yang dibuat untuk membantu pecinta drama Korea menemukan informasi drama, melihat trailer, dan menyimpan drama favorit.

Tentang Draela

Draela merupakan website sederhana yang menyediakan informasi tentang drama Korea seperti judul, tahun rilis, jumlah episode, rating, pemain, dan trailer.

Fitur Draela

Website ini memiliki beberapa fitur seperti mencari drama, melihat detail drama, menonton trailer, login, mencari berdasarkan tahun rilis dan menyimpan drama yang disukai ke dalam Favorite.

Project Pelatihan web

Draela dibuat sebagai project/ tugas akhir dari pelatihan web untuk menerapkan HTML, CSS, dan JavaScript dalam pembuatan website sederhana.
